⚠Safe replacement rule. Reuse the existing Blueprint ID, but leave Revision label blank (recommended) or enter a new label. The upload updates the mutable current Blueprint and records a new immutable DRAFT revision. It does not delete prior DRAFT, APPROVED, or RETIRED history.

✓Question Bank protection. Before any Blueprint write, every demand-row Subtopic_ID is checked against the newly loaded physical Class X Mathematics 10-MAT Question Bank rows. A mismatch rejects the Blueprint with no Blueprint write.

iApproval boundary. A replacement is stored as DRAFT. If an earlier revision is already APPROVED, any separate Formula consumer continues to resolve that approved frozen revision until an authorized reviewer approves the new one.

A successful replacement returns UPDATED; a first import returns IMPORTED.
