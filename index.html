Registry Context Onboarding

Privately govern one exact CBSE Class/Subject context before ordinary upload. The normal uploader never registers a key. An import-enabled context needs one exact existing Subject master and may be registered before its first Question Bank upload; Question Bank inventory is shown for review, not used as a veto. A planned physical context has no Subject master yet and stays non-resolvable until later promotion.

⚠Not automatic. This does not create or rename a Subject, Question Bank row, Chapter, Blueprint, or Format record. Import-enabled registration is available only on READY_TO_REGISTER; a future physical plan is available only on READY_TO_PLAN. Both require explicit confirmation and create immutable onboarding audit evidence.

Use the same private n8n shared secret above. Inspection is read-only; registration requires a separate explicit confirmation.

Approved Blueprint Export

Download the latest approved frozen revision for every matching Blueprint in one private Excel workbook. The workbook contains an index sheet and one complete demand-matrix sheet per Blueprint; it never exports DRAFT, RETIRED, or mutable current Blueprint content.

✓Latest approved revision only. When a Blueprint has several approved replacements, this export includes only the most recently approved revision for that Board, Class, Academic Subject Key, Academic Session, and Blueprint ID.

Uses the same private n8n shared secret above. This export is read-only.

Current Active Format Lookup

Privately review and download the formats that are currently active. The workbook includes active profiles, compiled contracts, sections, attempt groups, and active bindings. It never imports, activates, retires, or edits Format Catalogue records.

Uses the same private n8n shared secret above. Only currently active records are included.

Staged Question Review

Privately inspect staged Question Bank records before approving them. Approval is explicit, creates immutable per-question audit evidence, and applies only to currently eligible rows. Questions needing a supplied diagram/render asset remain blocked but can be exported for correction.

⚠Review before approving. Approval makes selected eligible questions available for use. It never edits question text, answers, options, source provenance, or taxonomy.

Use the same private n8n shared secret above. Lookup and export are read-only.
